# 🎙️ Радио ИИгла (Radio Iighla)

**Проект трансформации сознания через синтез науки, истории и философии.**

## 🌌 О проекте
«Радио ИИгла» — это интеллектуальная площадка, где стратегическое мышление встречается с современными технологиями. Мы создаем пространство для тех, кто ищет глубокие смыслы и готов к социальной трансформации.

## 🛠️ Технологический стек
Проект использует современные облачные решения для хранения данных:
* **Frontend:** HTML5 / CSS3 / JavaScript
* **Backend:** [Google Sheets API](https://www.google.com/sheets/about/) (Google Apps Script)
* **Hosting:** GitHub Pages / Dedicated Server


## 📖 Философия
Мы не просто транслируем звук — мы материализуем замыслы. Каждое сообщение в этом чате — шаг к цельной картине мира, где выводы следуют из предпосылок, а текст пробуждает к действию.
